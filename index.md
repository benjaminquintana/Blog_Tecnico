Mi primer blog técnico
Contexto
Durante un proyecto académico desarrollé una aplicación para organizar apuntes utilizando herramientas de inteligencia artificial. El objetivo era ayudar a estudiantes a ahorrar tiempo clasificando información.
Problema
Al comenzar el proyecto no tenía una estructura clara y resultaba difícil organizar los archivos y mantener el código ordenado. Esto provocaba errores y pérdida de tiempo.
Acciones
Primero analicé el problema.
Luego organicé el proyecto en carpetas.
Utilicé GitHub para guardar cada cambio mediante commits.
Después revisé el trabajo realizado e identifiqué qué decisiones habían funcionado y cuáles podían mejorarse.
Post-mortem
Lo que salió bien:
Organización del proyecto.
Uso de Git para registrar cambios.
Lo que salió mal:
Comencé a programar sin planificar suficiente.
Cómo evitarlo:
Definir primero la estructura del proyecto.
Realizar commits más pequeños y frecuentes.
Aprendizajes
Aprendí la importancia de planificar antes de programar, utilizar control de versiones y documentar el proceso para facilitar futuras mejoras.
